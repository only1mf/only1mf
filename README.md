I am a software engineer and security researcher specializing in **low-level systems development**, **binary reverse engineering**, and **full-stack web architecture**. My experience spans writing high-performance native software in C++ and C#, exploring ring-0 Windows kernel drivers, and engineering dynamic web backends and interfaces using PHP, modern JavaScript, semantic HTML5, and CSS3.

* 🔭 **Systems & Internals**: Windows kernel driver architecture, memory instrumentation, hooking, and binary analysis.
* 🌐 **Full-Stack Web**: Backend systems with PHP, performant frontends with modern HTML5/CSS3, and interactive client-side logic.
* 🛠️ **Native Applications**: High-throughput desktop tools, diagnostic CLI utilities, and UI integration via Dear ImGui.
* 🤝 **Collaboration**: Always open to discussions around security research, low-level tooling, and complex engineering challenges.
